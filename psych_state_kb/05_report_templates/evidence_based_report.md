# 证据导向状态观察报告模板

## 报告结构

### 【核心观察】
2-3句话概括本次对话中最突出的状态线索。

### 【逐条分析】
每条格式：
- **观察点**：用户反复/明确提到的模式
- **证据**：对应原话（至少1条）
- **可能解释**：列出2-3种可能性
- **不可直接判断**：这条线索不能说明什么
- **后续可确认**：下一步可以问什么来验证

### 【模式关联】
将多条独立线索串联，说明它们之间可能的共同线索（如都指向"自主权敏感"或"社交能量有限"）。

### 【置信度说明】
- 高置信度（反复出现+用户明确确认）→ 具体列出
- 中置信度（多次出现但未被确认）→ 具体列出
- 低置信度（单次出现）→ 具体列出

### 【未覆盖区域】
明确列出本次对话完全没有触及的维度，以及为什么它们可能重要。

### 【建议的下一步】
不是给用户建议，而是给观察者的下一步问题建议——哪些需要确认、哪些需要排除。
